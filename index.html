Algebra

Here are some basic algebraic concepts:

  • Variables: Symbols (usually letters) that represent an unknown value or a quantity that can change. Example: x, y.
  • Equations: A statement that two expressions are equal. Example: 2x + 3 = 7.
  • Functions: A relation between a set of inputs and a set of permissible outputs with the property that each input is related to exactly one output. Example: f(x) = x2.
